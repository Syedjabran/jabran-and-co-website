# Engineering audit — 2026-11-12

Scope: the whole repository (public site, CRM, client portal, shared JS),
all 12 deployed Edge Functions, and the production database's security
configuration. Method: line-by-line code review in four passes, read-only
catalog queries and anonymous-role tests on production (each inside
`begin read only; … rollback;`), Supabase security advisor, Vercel project
and deployment settings. No data was changed.

Status: **Fixed** = changed on branch `jabran/backend-hardening` ·
**Needs approval** = prepared, waiting for the owner ·
**Open** = recommendation, owner decides.

## E · Release checklist for this branch (on the Vercel preview, signed in as Owner)

1. CRM login: tap **Log In** → module appears and the login form is gone.
2. Press Enter in the password field 6 times → no lockout message.
3. Employees → edit an employee's department → Save → roles unchanged.
4. Finance → add a payment, double-click Save → one payment.
5. Financial Settings (from the sidebar) → three tabs load; add a test
   subscription, edit its cost, open History (one row), archive it.
6. Quotations, Orders, Opportunities → open an existing record → Save
   without changes → linked service/provider/order unchanged.
7. Public: home, contact, insights, case studies, 404 (`/x/y`) render; no
   console errors.

- `npm run graph` — regenerates `docs/CODEBASE-MAP.md` and `docs/codebase-graph.json`.
- Supabase → Advisors → Security / Performance.
- Anonymous-read test (safe, read-only):

  select count(*) from public.crm_receivables_payment_breakdown;
